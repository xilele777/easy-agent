# Windows 真实模型基准夹具

新增 [`scripts/benchmark-windows.ts`](../../scripts/benchmark-windows.ts)，为三道小型 JavaScript 修复任务创建独立临时 Git 仓库、预置失败的 Node 测试，并通过真实模型 Profile 调用构建后的 Easy Agent CLI。任务分别覆盖状态码边界、逗号列表解析和排序报表。

每题先确认测试在初始代码上失败，再执行模型，最后检查 CLI 退出状态、测试通过、目标源文件发生修改，以及 Git 状态中只有该源文件改变。Git 状态检查包含未跟踪文件。脚本输出每题的耗时、轮数、输入/输出 Token 与失败类别；退出时清理临时仓库，不输出 Key 或模型原始文本。复现命令已加入[测试说明](../../docs/testing.md)。

本夹具为显式运行的真实服务试跑，不进入默认离线门禁。模型配置只从本机用户设置及环境变量读取；运行时会产生模型调用。
