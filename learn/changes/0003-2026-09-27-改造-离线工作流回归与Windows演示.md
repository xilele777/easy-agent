# 离线工作流回归与 Windows 演示

> 改造日期：2026-09-27；起点提交：`3abd6df`。

新增[离线工作流回归](../../src/scripts/test-workflow-offline.ts)，用临时 Git 仓库和本地模型响应夹具，从 `QueryEngine` 入口验证 `Grep` 搜索、Plan Mode 阻止写入、默认模式请求一次性权限、工具结果回填、`/diff` 和 `/rewind`。该用例已加入默认离线门禁，并提供 `npm run test:workflow-offline` 单独运行入口。
