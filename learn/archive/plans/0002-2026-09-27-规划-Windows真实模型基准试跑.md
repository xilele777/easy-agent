# Windows 真实模型基准试跑计划

> 制定日期：2026-09-27；承接[已收口的 Windows 主线](../../handoff/0002-2026-09-27-交接-Windows优先主线阶段收口.md)与[原优化路线](../../plans/0000-2026-09-26-规划-优化与拓展路线.md)。

先用三道体量小、目标明确的 JavaScript 任务建立可复跑基线：状态码边界修复、逗号列表解析、排序报表。每题在独立临时 Git 仓库中预置源文件和 Node 内置测试，运行同一版 Easy Agent、同一 DeepSeek Profile。提示词要求仅修改产品代码、在 Windows 使用 PowerShell，并执行 `node --test`。

每题记录提交号、模型、初始文件与预期行为、提示词、CLI 退出状态、测试结果、Git 差异、耗时和输入/输出 Token 数。成功定义为 CLI 正常结束、测试通过且没有越过允许修改范围；失败要归类为模型、工具、权限、环境或断言问题。API Key 只从用户环境读取，不写入夹具或文档。首轮仅是小样本试跑，不据此推断总体成功率。

执行后在 `learn/reviews/` 新增基准结果，在 `learn/changes/` 记录基准脚本或夹具改造，并更新交接索引。后续扩充任务量或做多轮重复时仍沿用同样口径，以便比较。
